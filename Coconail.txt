Subject: UAT Observation – Unexpected Adobe Launch Property Loading on Offers Page
Hi Team,
During our implementation audit of the Offers page in UAT, we observed that Adobe Analytics event80 was firing on page load with a numeric value. As part of the analysis, we reviewed the existing FIS Adobe Data Collection property to identify the corresponding rule, data element and source responsible for populating this event.
However, event80 was not configured anywhere within the expected FIS property. Initially, we considered whether this could be caused by an outdated or mismatched Launch library version. Further debugging of the page source and script execution showed that two separate Adobe Launch library scripts are loading on the Offers page.
The additional Launch script appears to belong to a different property and application. A rule from this second property is responsible for setting and firing event80. Therefore, the event is not originating from the intended FIS implementation. Based on the current findings, it appears that this unrelated Launch library may have been included on the Offers page unintentionally.
This observation was identified in the UAT environment. We have not yet confirmed whether the same additional Launch script is also present in Production. We recommend asking the development team to:
Validate whether both Launch scripts are expected on the Offers page.
Check whether the additional property is also loading in Production.
Remove the unrelated Launch script from the Direct Bank application if it is not an approved dependency.
Revalidate the page after removal to confirm that event80 is no longer generated and that the intended Analytics implementation continues to work correctly.
If the same implementation is identified in Production, it should be addressed as a priority, since the additional property could generate unintended Analytics events, duplicate tracking or data being sent to an unrelated reporting configuration.
We have captured the relevant request details, source references and debugging evidence as part of the audit documentation.
