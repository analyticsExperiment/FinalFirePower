R33 – Target & Personalization Readiness
CIT Response:
We have created a detailed Adobe Target inventory covering 54 activities currently identified within the OAO/CIT.com scope. The inventory documents the activity-level dependencies, including the required mbox/profile parameters, audiences, offers, locations/scopes, experience details, and reporting dependencies. These dependencies need to be preserved and validated as part of the Web SDK migration so that existing activity qualification, offer delivery, rendering, and A4T/reporting behavior are not disrupted during the Phase 2 cutover. All required mbox/data inputs and associated offer dependencies identified in the inventory should therefore be migrated and validated prior to cutover.
R34 – Target & Personalization Readiness
CIT Response:
The implementation should not be designed only for the current Adobe Analytics reporting requirement. OAO banner impressions, banner clicks, and feature interaction events should be implemented through a reusable Web SDK/data-layer design that supports current Analytics measurement while also being suitable for future AJO offer decisioning and Target activation. The event structure should therefore retain the relevant interaction, page, customer/identity, banner/offer, and contextual information required for future personalization and activation use cases, avoiding the need for another major tagging redesign later.
