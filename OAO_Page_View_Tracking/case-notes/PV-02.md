# PV-02 · Promotion landing screen

The overview and detailed flows start promotion journeys at a landing page, with different actions for new and existing customers. The ticket limits page views to approved customer-visible OAO screens, so inventory membership and the displayed screen govern the event.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Confirm the entry screen’s inventory inclusion and use an active UAT promotion. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, Scope, §3.6 and AC4. OAO overview, high-level journey. Rate Promotion flows 1 and 7.
