# PV-04 · Manual Product Selection from CIT.com

The regular Welcome flows require manual product and code selection. The ticket tracks the logical screen rendering and puts product interaction events in their own scope. The page view keeps the screen’s approved identity while selections change. The paired columns use the readable inventory IDs and lowercase stages for the listed screen checks. Red cells identify values awaiting client confirmation.

**Comments.** Follow the sign-in/OTP path when required for the existing customer. Compare both runs to the approved mapping. Screen Checks SC-09.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.

**Sources.** Page-view ticket, Scope, §3.6 and AC7. Rate Promotion flows 2, 4, 6 and 8. Updated with the new inventory screenshots.
