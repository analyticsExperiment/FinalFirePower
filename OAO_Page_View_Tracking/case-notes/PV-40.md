# PV-40 · SPA navigation with a changed URL

AC3 includes SPA navigation. A changed route tests the screen and URL updates together, and the data-layer-before-WebSDK rule prevents stale values in the transmitted event. The paired columns use the readable inventory IDs and lowercase stages for the listed screen checks. Red cells identify values awaiting client confirmation.

**Comments.** Use a supported route pair and record both the browser URL and event payload. Use the applicable Screen Checks rows.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.

**Sources.** Page-view ticket, §§3.3–3.4 and AC3. Updated with the new inventory screenshots.
