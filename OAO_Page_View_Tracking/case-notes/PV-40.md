# PV-40 · SPA navigation with a changed URL

Move between two listed OAO screens using an Angular route that changes the URL without reloading.

**Expected.** Expect one pageView for the new screen. Its screen values and URLs must be updated before the Web SDK event.

**Why.** The ticket requires a pageView when an Angular transition shows a new screen. Red values need client confirmation. Actual values are for UAT.
