# PV-40 · SPA navigation with a changed URL

AC3 includes SPA navigation. A changed route tests the screen and URL updates together, and the data-layer-before-WebSDK rule prevents stale values in the transmitted event.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Use a supported route pair and record both the browser URL and event payload. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, §§3.3–3.4 and AC3.
