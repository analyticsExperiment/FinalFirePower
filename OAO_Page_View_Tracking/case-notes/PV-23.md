# PV-23 · Manual or fraud-review outcome screen

The high-level overview shows Manual / Fraud Review and Need More Information. A review outcome can still display an in-scope screen. Its page view follows the visible screen’s inventory identity.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Use a review fixture and record the visible outcome and inventory rule. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.
