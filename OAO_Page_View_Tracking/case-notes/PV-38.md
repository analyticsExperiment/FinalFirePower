# PV-38 · Resume an existing application

The overview provides a Resume branch and AC5 specifically requires tracking screens actually displayed after resumption. The resume point and inventory determine the sequence and mappings.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Record the saved application’s resume point and visible sequence. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.
