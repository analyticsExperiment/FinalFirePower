# PV-08 · Review Primary Applicant Information

The flow places a review page after the primary applicant details. This is a distinct visible step, so its own approved identity is the expected value. The comparison catches applicant-page attributes carried into review.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Compare the review event to the preceding applicant-information event. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, AC1 and AC3. Rate Promotion flows 1–2.
