# PV-08 · Review Primary Applicant Information

The flow places a review page after the primary applicant details. This is a distinct visible step, so its own approved identity is the expected value. The comparison catches applicant-page attributes carried into review. The paired columns use the readable inventory IDs and lowercase stages for the listed screen checks. Red cells identify values awaiting client confirmation.

**Comments.** Compare the review event to the preceding applicant-information event. Screen Checks SC-19.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.
