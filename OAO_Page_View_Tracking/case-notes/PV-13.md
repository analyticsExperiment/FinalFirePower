# PV-13 · Review Joint Applicant Information

The flow includes a distinct review step for the joint applicant. Its approved identity is needed even when the review and detail screens share a URL. The expected event is tied to this review rendering. The paired columns use the readable inventory IDs and lowercase stages for the listed screen checks. Red cells identify values awaiting client confirmation.

**Comments.** Use the joint-review mapping and compare it with the preceding joint-detail event. Screen Checks SC-24.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.
