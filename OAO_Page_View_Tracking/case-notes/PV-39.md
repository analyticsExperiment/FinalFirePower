# PV-39 · SPA navigation with an unchanged URL

Section 3.6 explicitly requires page views for new logical screens even when the URL stays the same. This pair checks that the screen identity comes from the rendered logical screen.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Use a supported same-URL screen pair and capture the event order and both mappings. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, §3.6, AC1 and AC3.
