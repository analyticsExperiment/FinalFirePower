# PV-03 · Prefilled Product Selection from the landing page

Start a new application from the promotion landing page. Open Product Selection and check the prefilled product and promotion code.

**Why.** The landing-page flow shows Product Selection with a prefilled product and code. Red values need client confirmation. Actual values are for UAT.
