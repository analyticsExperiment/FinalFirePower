# PV-03 · Prefilled Product Selection from the landing page

Rate Promotion flow 1 supplies the product and code prefill. Those values make the navigation setup concrete. The page view is triggered by the rendered Product Selection screen. Its analytics identity comes from the approved inventory.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Use the product wording and offer code configured in UAT. Capture the displayed prefill. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, AC1–AC2 and AC4. Rate Promotion flow 1, steps 1–2.
