# PV-10 · Joint Applicant Information Page 1

Flow 2 includes joint applicant pages after Configure Account. Choosing joint ownership exposes this conditional step. Its identity must be the inventory entry for Joint Applicant Information Page 1. The paired columns use the readable inventory IDs and lowercase stages for the listed screen checks. Red cells identify values awaiting client confirmation.

**Comments.** Use a joint UAT application and approved applicant data. Screen Checks SC-21.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.
