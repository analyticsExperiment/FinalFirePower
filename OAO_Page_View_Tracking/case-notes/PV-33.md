# PV-33 · Enroll Account with no prior Platinum Savings account

Use an existing customer who never had Platinum Savings. Open Enroll Account and choose Open New Account.

**Expected.** Expect a pageView for each OAO screen shown. No pageView is expected for Successfully Enrolled when it is skipped.

**Why.** A customer without a prior Platinum Savings account follows the documented Open New Account branch. Red values need client confirmation. Actual values are for UAT.
