# PV-42 · Genuine screen revisit or reload

Section 3.6 permits page views when revisited screens are genuinely rendered again. The approved identity stays stable, while the event timestamp and current URLs describe the new rendering.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** Record separate rendering boundaries and event counts for each action. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, §§3.1 and 3.6, AC1 and AC7.
