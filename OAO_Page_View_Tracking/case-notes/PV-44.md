# PV-44 · URL with an Adobe entry parameter

Section 3.3 supplies this exact URL example and says CIT.com or D1 entry may carry Adobe/campaign parameters. The expected fields preserve the full browser URL and its normalized form respectively.

Use **Required payload checks** in the workbook for the seven fields. Match each screen’s approved inventory identity and compare its data-layer values with Network and Adobe Assurance.

**Comments.** xxxx is a dummy ticket value. Use the approved UAT entry parameter for the actual run. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Page-view ticket, §3.3 and AC1.
