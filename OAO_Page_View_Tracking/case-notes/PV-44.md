# PV-44 · URL with an Adobe entry parameter

Section 3.3 supplies this exact URL example and says CIT.com or D1 entry may carry Adobe/campaign parameters. The expected fields preserve the full browser URL and its normalized form respectively. The paired columns use the readable inventory IDs and lowercase stages for the listed screen checks. Red cells identify values awaiting client confirmation.

**Comments.** xxxx is a dummy ticket value. Use the approved UAT entry parameter for the actual run. Screen Checks SC-01.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.
