# AA-01 · New individual application without a promotion

OAO assigns the new customer an Application ID before product selection. Appendix A supplies the Personal individual no-promo fixture. `New` requires `ambiguous` and a literal `null` IDP. The promotion fields use `false`, `"no code"`, `"not applicable"` and `"not applicable"`. The ticket illustrates the funded branch with `Electronic Transfer`, `Initiated` and a numeric USD deposit of `100.00`.

Use **Required payload checks** for the shared fields. Compare the push with Network and Adobe Assurance and reconcile the Application ID in OSP.

**Comments.** Capture the ID created at Open Account Now. Reconcile it to the auto-approved OSP application. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.
