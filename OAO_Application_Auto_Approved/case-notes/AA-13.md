# AA-13 · Event timing from Funding through Processing to Finish

Processing connects Funding to the decision page. The ticket assigns the event to the finish-page load. The expected count is zero at each earlier screen and one when the qualifying result first appears.

Use **Required payload checks** for the shared fields. Compare the push with Network and Adobe Assurance and reconcile the Application ID in OSP.

**Comments.** Record the event count at each screen. Keep the browser Network log across the transitions. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** OAO overview, New-account journeys. Forwarded ticket, Scope, Out of Scope and Additional Criteria (finish-page-only trigger).
