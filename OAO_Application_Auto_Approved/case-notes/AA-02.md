# AA-02 · New customer with a prefilled rate promotion

The landing page preselects Platinum Savings and supplies the code. Save and Continue confirms the code and its offer ID for `CUSTOMRAT`. The flow selects Mail-in Check, shown as `Mail in Check` in the ticket example. Use the approved funding value and finish-page status and amount. The customer fields follow the `New` rule.

Use **Required payload checks** for the shared fields. Compare the push with Network and Adobe Assurance and reconcile the Application ID in OSP.

**Comments.** Use the approved Platinum Savings rate fixture. Capture the confirmed code before leaving Product Selection. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.
