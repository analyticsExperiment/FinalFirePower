# AA-11 · Joint application with one declined applicant

The ticket requires every applicant to be auto-approved. A decline for either applicant defeats that condition, so the expected event count is zero.

**Comments.** Record the application status and both applicant decisions to establish the test setup. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** OAO overview, New-account journeys (decline outcome). Forwarded ticket, Acceptance Criteria, Scenario 2 and Additional Criteria (applicant decisions).
