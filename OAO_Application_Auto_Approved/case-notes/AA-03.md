# AA-03 · New joint application with a manually entered rate code

The regular Welcome flow documents manual product/code entry, joint applicant pages and electronic funding. These steps drive `ownershipType = "joint"`, `accountType = "Personal"` and the saved rate offer. `customerType = "New"` still governs `ambiguous` and `IDP = null`. Both applicant decisions are needed for the approval trigger.

Use **Required payload checks** for the shared fields. Compare the push with Network and Adobe Assurance and reconcile the Application ID in OSP.

**Comments.** Use the approved rate fixture and verify both applicant decisions under the same Application ID. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.

**Sources.** Rate Promotion detailed flows, flow 2. Forwarded ticket, §3.2 and Additional Criteria (both applicants, final confirmed code).
