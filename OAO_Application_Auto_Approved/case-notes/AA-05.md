# AA-05 · Existing customer opens a custodial account

The paired columns contain all 23 required fields. Fixed strings and conditional booleans follow the ticket. Customer, ownership and funding values follow this row's stated fixture. Application ID, time, IDP and funding status are matched to the current OAO/OSP run. Red fields need approved product/offer data; ticket-only examples are described in the field rules.

**Comments.** Use an eligible custodial product. Compare the submitted product and OSP record for the same application. Red fields need approved fixture data. Runtime fields must match the current run.

**Actual fields, Actual Result and Screenshot** are blank for UAT. **Status** is **Not run**. Each Expected value has a separate Actual column.
