# AA-05 · Existing customer opens a custodial account

The ticket distinguishes the account classification `Custodial` from the ownership value `custodial`. Apply the existing-customer rule to the approved signed-in fixture. No offer was confirmed, so the promotion object keeps the ticket’s no-promotion values. The funded case takes its funding values from OAO.

Use **Required payload checks** for the shared fields. Compare the push with Network and Adobe Assurance and reconcile the Application ID in OSP.

**Comments.** Use an eligible custodial product. Compare the submitted product and OSP record for the same application. **Actual Result** and **Screenshot** are blank for UAT. **Status** is **Not run**.
